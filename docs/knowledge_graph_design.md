# 风电领域知识图谱设计

## 图谱结构

### 节点类型

下面的条目是设计示例，不是完整枚举。当前节点与边的实际规模以 `data/knowledge_graph.json` 为准，可运行 `python src/rag_cli.py stats` 查看。

1. **部件** - 风电机组主要部件
   - 齿轮箱
   - 发电机
   - 叶片
   - 变桨系统
   - 偏航系统
   - 液压系统
   - 制动系统
   - 塔筒
   - 变压器

2. **故障类型** - 常见故障
   - 磨损
   - 过热
   - 泄漏
   - 卡死
   - 裂纹
   - 腐蚀

3. **症状** - 故障表现
   - 温度异常
   - 振动增大
   - 噪音异常
   - 压力下降

4. **原因** - 故障原因
   - 润滑不良
   - 过载运行
   - 密封失效
   - 材料疲劳

5. **解决方案** - 处理措施
   - 更换部件
   - 修复处理
   - 调整参数
   - 清洁维护

6. **维护操作** - 维护活动
   - 日常巡检
   - 定期维护
   - 故障处理

### 关系类型

当前实现已生成的关系类型：

1. **HAS_FAULT** - 部件具有某种故障
2. **HAS_SYMPTOM** - 故障具有某种症状
3. **CAUSED_BY** - 故障由某种原因引起
4. **SOLVED_BY** - 故障由某种方案解决
5. **REQUIRES** - 维护操作需要某种部件

**PREVENTS** 是保留的设计关系，目前图谱生成器没有输出该关系。后续接入预防措施语料时再启用，不应把它当成当前已实现关系统计。

## 示例图谱

```
齿轮箱 --HAS_FAULT--> 齿轮磨损
齿轮磨损 --HAS_SYMPTOM--> 振动增大
齿轮磨损 --CAUSED_BY--> 润滑不良
齿轮磨损 --SOLVED_BY--> 更换齿轮
日常巡检 --REQUIRES--> 齿轮箱
定期维护 --PREVENTS--> 齿轮磨损（预留关系示例，当前数据未生成）
```

## 实现方案

使用Python字典实现轻量级知识图谱，无需Neo4j：
- 节点存储为字典
- 关系存储为邻接表
- 支持图谱查询和遍历
- 可集成到RAG检索增强
