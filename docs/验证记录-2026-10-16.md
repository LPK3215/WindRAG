## 三、观察项（不是本轮缺陷，留待后续）

1. 规模化语料下，示例问题"变速箱异响怎么排查？"会被覆盖率判据拒答：查询里的稀有别名"变速箱"
   在检索到的 3 篇文档中未出现（该语料里齿轮箱没有"异响"故障，命中的是偏航电机异响工单），
   导致 IDF 加权覆盖率只有 0.22。行为与 README 记录的拒答边界一致，但拒答话术没有点出
   "该部件不存在该故障"这一真实原因，可读性可以更好。若要改进，方向是拒答归因排序
   （先组合校验、后覆盖率）而非调阈值，调阈值会破坏现有 100% 的域外拒答。
2. `口语化查询层 Recall 58%` 与 `域内缺资料拒答 33%` 是已知边界（README「口语化查询验证」），
   根因是缺少真语义表示，属后续稠密向量方向，不在"纯 Python"主线内。
3. 遗留研究版（`run_rag.py`/`gradio_app.py` 等）本机缺 gradio 包无法启动，按 AGENTS.md
   「项目自身需求」第 3 条只作对照留存，本轮不改不删。
