🌬️ WindRAG

风电领域智能诊断问答系统 — 基于多策略混合检索与知识图谱增强的 RAG

v1.0.0 · Python 3.10+ · jieba + BM25 · 知识图谱

项目简介

🎯

核心价值

面向风力发电领域的智能故障诊断问答系统，采用 RAG 架构，融合向量语义检索、BM25 关键词检索和知识图谱结构检索三种策略。

💡

核心特性

  • 自适应混合检索（动态调整融合权重）
  • 知识图谱增强（embedding 语义匹配）
  • 模型池管理（多 LLM 自动切换）
  • 中文深度优化（jieba + 领域术语）
  • 高鲁棒性设计
