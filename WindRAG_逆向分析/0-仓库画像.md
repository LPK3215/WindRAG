## 关键事实（已读源码确认）

- **协议**：MIT（`README.md`、仓库 LICENSE）。
- **核心依赖**（`requirements.txt`）：`sentence-transformers`(text2vec-base-chinese)、`rank_bm25`、`networkx`、`gradio`、`openai`(ModelScope API 兼容)、`scikit-learn`、`numpy`、`python-dotenv`。
- **数据源**：全部是**合成数据**，无真实风电手册。
  - `data/synthetic/fault_cases.json`（故障案例）、`technical_docs.json`（技术文档）、`operations_manual.json`（运维手册）、`qa_pairs.json`（问答对）。
  - 另有 `data/OpenWindSCADA/`（39文件，含 csv/png/py/ipynb）——⚠️ 待核实：看目录名疑似外部 SCADA 数据集，但代码未引用，疑似遗留/未接入。
- **索引产物**：`data/processed/chunks/`、`data/processed/index/`、`data/knowledge_graph.json`、`data/adaptive_model/`。
- **外部 LLM**：仅支持 ModelScope（`query_models.py:14` `BASE_URL="https://api-inference.modelscope.cn/v1"`），通过 `config.env` 注入 `MODELSCOPE_API_KEY`（`query_models.py:10-13`）。

## 不属于什么（排除项）

- 不是 Agent 编排类（无 tool 注册/状态机/多 agent）。
- 不是模型路由·推理优化（模型池仅做"可用性切换+降级"，无成本/延迟路由决策）。
- 不是全栈工程类（无鉴权、无数据库、无 REST API 契约，仅 Gradio 单页）。

→ 因此第2步分析重点按**RAG·知识库类**展开：文档解析与切分策略、检索（关键词+向量+重排）、引用回链与可追溯性、数据源接入。
