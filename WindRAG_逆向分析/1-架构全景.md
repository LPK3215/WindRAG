# 1. 架构全景

## 1.1 模块划分（src/ 16个文件）

```
入口层（3个）
├─ interactive_rag.py        命令行交互入口
├─ gradio_app.py             Web UI 入口 (端口7860)
└─ (test_rag.py / query_models.py / test_modelscope.py)  工具/验证入口

核心层（1个 · 中枢）
└─ run_rag.py                WindTurbineRAG 主类：编排检索+生成，聚合所有子模块

能力层（6个）
├─ data_processing.py       数据加载 + 文档切分(chunking)
├─ build_index.py           离线构建 FAISS/NumPy 向量 + BM25 + 持久化
├─ knowledge_graph.py       知识图谱(NetworkX) + 语义查询
├─ query_features.py        查询特征提取(规则) + 领域词典
├─ adaptive_fusion.py       自适应融合 MLP(规则先验+残差) 推理
└─ model_manager.py         线程安全 LLM 模型池 + 降级

训练/实验层（4个）
├─ generate_training_data.py   生成融合权重训练样本
├─ train_adaptive_fusion.py    训练 MLP 融合模型
├─ ablation_experiment.py      固定α vs 自适应α 对比实验
└─ evaluation.py / system_validation.py  检索/答案/稳定性评估

配置层（1个）
└─ (config.env 在仓库根，非 src/)  MODELSCOPE_API_KEY 等
```

## 1.2 依赖关系（谁 import 谁）

- `run_rag.py` 是**唯一中枢**，import 全部能力层 + 训练产物：
  - `from data_processing import DataProcessor`
  - `from build_index import IndexBuilder`
  - `from knowledge_graph import KnowledgeGraph`
  - `from query_features import QueryFeatureExtractor`
  - `from adaptive_fusion import AdaptiveFusionModel`
  - `from model_manager import LLMModelManager`
  - 训练产物：`data/adaptive_model/adaptive_fusion_model.joblib`、`data/adaptive_model/scaler.joblib`、`data/adaptive_model/feature_names.json`（`run_rag.py:158-162`）
- 入口层只依赖 `run_rag.WindTurbineRAG`（`gradio_app.py:14`、`interactive_rag.py:9`、`test_rag.py:9`）。
- 实验层依赖 `run_rag.WindTurbineRAG` + `query_features`（`ablation_experiment.py:16-17`）。
- **依赖方向单向、无循环**：入口 → 核心 → 能力 → 训练产物。这是该原型最干净的设计点。

## 1.3 核心抽象（已读源码）

1. **`WindTurbineRAG`（`run_rag.py:101`）**——系统门面(Facade)。持有 `model`(SentenceTransformer)、`embeddings`、`bm25`、`kg`、`model_manager`、`adaptive_fusion`、`query_feature_extractor` 全部子组件；对外仅暴露 `query()` 与 `retrieve_documents()`。
2. **`DomainConfig`（`run_rag.py:37-92`）**——风电领域配置单例：组件列表、故障类型、维护类别、标准清单(GB/IEC/ISO)、领域术语与数值模式。是"垂直化"的核心载体。
3. **`AdaptiveFusionModel`（`adaptive_fusion.py:14`）**——封装 `predict_alpha(query, query_emb)`：加载 scaler + MLP，输出 [0,1] 融合权重。
4. **`LLMModelManager`（`model_manager.py:15`）**——封装模型列表 + `get_response()` 的降级循环 + `threading.Lock`。
5. **`KnowledgeGraph`（`knowledge_graph.py:11`）**——封装 NetworkX 图 + `semantic_query()` + `get_node_info()`。
