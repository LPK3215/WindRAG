# 4. 设计取舍与亮点 / 局限与坑

---

## 4.1 设计亮点（作者的聪明选择）

1. **「规则先验 + MLP 残差」自适应融合**（adaptive_fusion.py:65-135）
   - 兼顾可解释性与数据驱动微调，是解决"混合检索权重怎么定"问题的优雅方案，优于网格搜索固定 α 或纯黑盒 MLP。
2. **三路检索互补**（run_rag.py:182-214）
   - 向量(语义) + BM25(精确词/编号) + KG(实体关系) 各取所长，对风电领域"既有多标准编号、又有口语故障描述"的查询形态覆盖好。
3. **LLM 模型池 + 优雅降级**（model_manager.py:77-116 + run_rag.py:370）
   - 无 LLM / 模型全挂时不崩，回退模板答案，保证系统可用性。线程锁支持并发。
4. **Facade 聚合**（run_rag.py）——入口层极简，子模块可独立迭代。
5. **合成数据自洽闭环**——`generate_training_data` → `train` → `build_index` → `query` → `evaluation/ablation` 全链路可一键跑通，适合教学/复现。

---

## 4.2 为亮点牺牲了什么（取舍代价）

| 取舍 | 牺牲 |
|------|------|
| 自适应融合用合成标签训练 | 真实泛化性未严格验证，规则先验占比大，MLP 残差贡献可能有限 |
| KG 用"节点描述向量召回"而非图推理 | 失去图谱真正的多跳/关系推理价值，与纯向量召回同质化 |
| 重排用朴素余弦（无 cross-encoder） | 重排质量上限低，对困难负样本区分力弱 |
| 模板降级答案 | 无推理能力，仅 component 命中时有效，长尾问题答非所问 |
| 全局 `config.env` + `sys.path.append('.')` | 不可多环境隔离，部署需手动改路径 |

---

## 4.3 局限与坑（分析者发现的隐患）

1. **重排实现是"伪重排"**：`_rerank_documents`（run_rag.py:258-278）只是对**已融合候选**再算 query-doc 余弦、按相似度排序。它等于把向量检索又做了一次，并未引入更强信号，且 KG 结果若融合后进入候选也会被重排打乱"图谱命中"的展示语义。⚠️ 效果增益可疑。
2. **KG 与向量/BM25 融合不对等**：KG 结果不走 α 加权、直接 append（run_rag.py:210-214），导致"图谱命中"数量不可由 α 调控，三路实际上变成"两路加权 + 一路附加"。
3. **无端到端引用回链**：答案文本不含来源角标，用户难核验（见 2.4）。Gradio 只在侧栏列文档，对话流中断链。
4. **FAISS 用法保守**：`build_vector_index` 用 `IndexFlatIP`（build_index.py:50-52）即暴力内积，数据量小可接受，但无量化/IVF，扩到万级文档会慢。
5. **切分无 overlap、无结构感知**（data_processing.py:175-224）：长参数表、跨句指代会被切断。
6. **评估指标不严谨**：
   - `evaluation.py` 用"关键词匹配率"而非真实相关性标注；
   - `ablation_experiment.py` 的"检索质量(WDS)"用 query-doc 余弦当 proxy（ablation_experiment.py:86-108），非 nDCG，且与融合所用的余弦同源，存在度量自相关偏倚。
7. **模型池无错误类型路由**：限流/超时/鉴权错统一 try_next，可能把"key 失效"也当瞬时错反复重试（model_manager.py:77-116）。
8. **线程安全的边界**：`Lock` 只保护"选哪个模型"，不保护"同一模型并发请求"；高并发下共享 OpenAI client 仍可能出问题（model_manager.py:91）。
9. **数据层 `OpenWindSCADA/` 未接入** ⚠️ 待核实：39个文件疑似真实 SCADA 数据，但代码无任何 import/引用，属遗留或待开发分支。
10. **无测试覆盖声明**：`test_rag.py` 仅是手跑打印，无断言；`system_validation.py` 是稳定性 demo，非 CI 测试。

---

## 4.4 可改进点（若继续演进）

- 重排换 cross-encoder（`bge-reranker`）；KG 升级为多跳子图检索或 graph-RAG。
- 答案内联引用标记 `[i]↩source`；切分加 overlap + 结构感知。
- 训练标签用人工标注 query→理想α，替代纯合成。
- 模型池按异常类型分流（429 退避、401 立即告警）。
- FAISS 换 IVF/PQ；引入配置中心替代 `config.env` 硬编码。
