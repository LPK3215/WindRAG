## 一句话结论

WindRAG 是一个**风电领域垂直 RAG 问答系统**：以脚本化科研原型形态，把"向量语义 + BM25关键词 + 知识图谱结构"三路检索，用「规则先验 + MLP残差」预测的自适应融合权重组合，再经余弦重排后送 LLM（或无 LLM 时模板降级）生成答案。设计亮点在**查询自适应的混合检索融合**与**鲁棒的模型池降级**，短板在**重排/图谱是朴素实现、知识图谱为人工三元组且缺乏引用回链**。
